# Clawd

Quadros do mascote Clawd usados na página "IA" da ilha (`clawd_sprite.py`).
Criação de Fabio Castilho, do projeto [clawd-mascot](https://github.com/FabioCastilho/clawd-mascot), com a mesma licença MIT.

Animações: `f0`–`f7` (parado), `h0`–`h7` (trabalhando), `f25`–`f30` (alerta), `h16`–`h23` (terminou), `g24`–`g30` (dormindo).
